# Comuni italiani — fonte e riproducibilità

Fonte: ISTAT, [Codici delle unità amministrative](https://www.istat.it/classificazione/codici-dei-comuni-delle-province-e-delle-regioni/).
File ufficiale: [Elenco-comuni-italiani.xlsx](https://www.istat.it/storage/codici-unita-amministrative/Elenco-comuni-italiani.xlsx).
Edizione indicata nella pagina fonte: 21 febbraio 2026; acquisizione Scoutly: 17 ottobre 2026.

comuni.json è un’elaborazione dei dati ISTAT: per ogni riga conserva le colonne E (codice alfanumerico a sei cifre), F (denominazione italiana e straniera) e O (sigla provinciale), ordinate per denominazione. 7.894 record, codici univoci; Milano: 015146, MI. Nessuna informazione personale o contatto.

Il browser ricerca solo in questo file statico: il testo digitato non viene inviato a un servizio di geocodifica. La versione server usa lo stesso file per verificare codice, denominazione e coerenza con il perimetro Milano/altro comune. Aggiornare lo snapshot da fonte ufficiale e rifare i controlli prima di una futura sostituzione; nessuna dipendenza da uno scraping eseguito durante la compilazione del form.
